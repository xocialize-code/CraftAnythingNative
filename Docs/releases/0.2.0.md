Craft Anything Native now drives the Craft Anything engine at upstream 0.4.0. 0.1.0 shipped the engine's 0.2.0.

Our fork of the engine is now rebased onto upstream `main` (`fc93bd0`, 2026-11-05) instead of taking single
changes from it. It carries the same additions as before: the SwiftUI stack, the app's tool server, plugins that
stand in for built-in tools, and each project's record of the browser that pictured it.

What changes for you, from the engine:

- **Safer builds.**
  - Builder file tools and approvals no longer follow a link out of the project.
  - Auto mode reads paths with spaces or capitals correctly when it decides on a delete.
  - Claude Code builders get an explicit list of built-in tools, so tools that message other sessions, publish or
    schedule work never start. Clean room chats and questions refuse the agent's own file, shell and web tools
    outright.
  - Previews of a build answer only this computer.
- **Claude Code sees every tool again.** One tool's schema made Claude Code drop the whole Craft Anything tool list.
- **Website captures** scroll through the page before photographing it with the engine's browser. They record CSS
  colours as the page's own values and say when a page's HTML was cut at 4 MiB. Page states open each width's own
  controls, and put a tab back after photographing another one.
- Many fixes from upstream's parser hardening and its handling of Claude Code, across about 290 changes. The
  engine's own release notes have the details.

Websites pictured with WebKit run the engine's updated page scripts too. Projects keep the browser that pictured
them, as before.
