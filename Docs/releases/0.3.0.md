Craft Anything Native gets Deep mode, and game pictures made on this Mac through Gaea. It still drives the Craft
Anything engine at upstream 0.4.0, through our fork.

What's new:

- **Deep mode.** Clean room, the only mode until now, never looks inside the original. Deep mode can read its code,
  files and page source, which helps when a build has to match how the original really works.
  - Switch between them in the title bar or in Settings. Turning Deep on asks first, and the engine's tool list
    follows the switch.
  - A new build asks how closely Craft Anything may look at the original, with a short description of each mode.
  - When Clean room refuses something, the app says so and offers Deep mode, instead of an error.
  - Settings shows whether Ghidra is installed. Get Ghidra installs it for the deepest look at programs, with its
    progress.
- **Game pictures from Gaea.** A game build can make its own pictures: switch on Game assets for a new build
  (Godot, Unity, Unreal Engine or Rust + macroquad, or when the builder chooses).
  - Pictures come from Gaea, the media server on this Mac. They're free, need no key, and the builder sees their
    progress ("denoise 5/8"). Each one is credited in the game's CREDITS.md with the model and its licence.
  - Settings › Game assets shows whether Gaea is running and which picture models it has. Choose one, or let Gaea
    pick the one that fits this Mac's memory.
  - fal.ai's picture models are still there with a key, and 3D models still come from fal.ai.
- **A file moved after it was opened is named.** When a file opened in Deep mode is moved, renamed or changed before
  a build turn, the builder now says which file and to open it again. It used to stop with "Craft Anything's tools
  did not start in Claude Code".
- **An action's error stays shown.** A project's error from an action no longer disappears when the project
  refreshes.

To make game pictures, Gaea needs to be running with a picture model, for example
`gaea plugins add https://github.com/xocialize-code/gaea-plugin-z-image`. The first picture after adding a plugin
can take several minutes; later ones take about 10 to 20 seconds.
