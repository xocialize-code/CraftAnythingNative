The first release of Craft Anything Native: a SwiftUI app for Mac that drives the Craft Anything engine, bundled.

- **New Build**: describe what to make, give it an original (none, a website, or an app or file), pick the stack and
  the number of rounds.
- **Projects**: status, the conversation, questions to answer, checks, the latest screenshot; send a note or a
  follow-up, stop the build, play the result or show it in Finder.
- **Tools**: every engine tool, with a form built from its schema.
- **Approvals** the engine asks for appear as a sheet.
- **Websites pictured with WebKit**, when you turn it on: the app carries `craft-anything-native-tools`, a plugin that
  serves the engine's website browser set with WebKit. It isn't on by default. To turn it on, add the entry it prints
  to the engine's `config.toml` (`~/Library/Application Support/craft-anything/config.toml`):

  ```sh
  "/Applications/CraftAnythingNative.app/Contents/MacOS/craft-anything-native-tools" --print-config
  ```

  Each project keeps the browser that pictured its original, so projects already studied with Chromium stay on
  Chromium.
